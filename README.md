> ### АНТИВИРУСЫ
> Антивирус может отреагировать на WinDivert.  
> WinDivert перехватывает и фильтрует трафик; без него zapret не работает.
> Этот инструмент способны использовать и полезные, и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов считает файлы WinDivert потенциально опасными или относит их к хакерским инструментам. В результате файл удаляется и попадает в карантин. Обычно такое обнаружение называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Поместите папку с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky содержит параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, предпочтительнее добавить исключение; при недостаточном понимании настроек рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется
    * Владельцам роутеров Keenetic следует включить параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут нарушиться

2. Получите zip/rar-архив с [последнего релиза](https://github.com/IndustrialAxe/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте "Разблокировать". Для 7-Zip и PeaZip этот шаг не требуется

4. Извлеките архив в каталог, в пути которого нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — запуск стратегии вручную

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные инструменты:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб: стратегии в автозапуске и WinDivert
  - **`Game Filter`** — включение или отключение обхода для игр и прочих сервисов, использующих UDP и TCP-порты выше 1023.  
  **После смены параметра стратегию необходимо перезапустить.**  
  В скобках показывается текущий статус (включено/выключено).
  - **`IPSet Filter`** — управление обходом сервисов, перечисленных в `ipset-all.txt`.  
  Это может помочь при проверке ресурса, который не работает только при включённом zapret  
  Возможные состояния:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP сверяется со списком
    - `any` — фильтр применяется к любому IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена активного фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручной поиск обновлений
  - **`Run Diagnostics`** — проверка распространённых причин неработоспособности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работу приложения
  - **`Run Tests`** — инструмент для проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/IndustrialAxe/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и запустите **`Update hosts file`**. Если установленный hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - В открывшейся папке найдите `hosts` и откройте его текстовым редактором от имени администратора
  - Вставьте скопированное в конец файла `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что hosts действительно был сохранён.

#### Работа не гарантирована. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/IndustrialAxe/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вначале конкретная стратегия может работать, но после её обнаружения перестать обходить блокировку.
> Здесь собрано много разных стратегий. Если готовые варианты не помогают, создайте новую на основе одной из них и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте отсутствие ошибок через `service.bat` -> `Run Diagnostics`

- Убедитесь, что нужный адрес присутствует в доменных или IP-списках

- Испытайте другие стратегии (**`ALT`**, **`FAKE`** и прочие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/IndustrialAxe/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Выполните `service.bat` -> `Run Diagnostics`; исправьте ошибки и в конце ответьте Y
- Удалите каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/IndustrialAxe/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть "Разблокировать", включите этот пункт, нажмите применить и затем ОК
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте ресурсы. Если интернет-сайты не открываются, закройте программу через значок замка на панели задач и выберите другую стратегию
- Найдя рабочий вариант, включите автозапуск: `service.bat` -> `Install Service` -> выберите стратегию

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. В противном случае могут стать недоступны неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если ранее всё работало.
- См. также [#251](https://github.com/IndustrialAxe/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` выполните `Run Diagnostics`, затем очистите кэш Discord.
- Проверьте Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если браузер также не подключается, повторно протестируйте все стратегии. YouTube и Discord могут работать на разных стратегиях.
- См. также [#252](https://github.com/IndustrialAxe/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/IndustrialAxe/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно стоит сделать следующее:
- через `service.bat` обновить ipset и включить `Game Filter`
- если это не помогло, дополнительно включить `ipset any`

Учтите: режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/IndustrialAxe/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/IndustrialAxe/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Расширить список обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены включаются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например если сеть указана в `ipset-all.txt`, но конкретный домен фильтровать не следует
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети
  - Файлы **`*-user.txt`** будут созданы автоматически при первом запуске `zapret` или `service.bat`
